# Common Query Patterns for Chatbot Optimization

## Question Frameworks

### Informational Queries

**What Questions:**
- What is [concept]?
- What are the benefits of [topic]?
- What causes [problem]?
- What are the best [items] for [purpose]?

**How Questions:**
- How does [process] work?
- How to [accomplish task]?
- How do I [solve problem]?
- How much does [item] cost?

**Why Questions:**
- Why is [phenomenon] important?
- Why does [event] happen?
- Why should I [take action]?

**When Questions:**
- When should I [take action]?
- When is the best time to [activity]?
- When did [event] occur?

**Where Questions:**
- Where can I [find/buy/access] [item]?
- Where is [location/information] located?

**Who Questions:**
- Who invented [item]?
- Who should [take action]?
- Who is [person/role]?

### Comparison Queries

**Direct Comparisons:**
- [X] vs [Y]
- [X] versus [Y]
- Difference between [X] and [Y]
- [X] or [Y]

**Better/Best:**
- Is [X] better than [Y]?
- Which is better, [X] or [Y]?
- Best [category] for [purpose]
- Top [number] [items]

### Problem-Solution Queries

**Troubleshooting:**
- [Problem] not working
- How to fix [issue]
- Why isn't [thing] working?
- [Error message] solution

**Recommendations:**
- What's the best [item] for [situation]?
- Should I [option A] or [option B]?
- Which [item] should I buy?

### Temporal Queries

**Current State:**
- Current [statistic/status]
- Latest [news/update]
- [Topic] in 2024
- Recent developments in [field]

**Future:**
- Future of [technology/field]
- Will [event] happen?
- When will [future event] occur?

**Past:**
- History of [topic]
- How did [event] happen?
- What happened with [event]?

## Query Intent Mapping

### Navigational Intent
User wants to reach a specific page or resource.

**Patterns:**
- [Brand name] + [product/service]
- [Company] login
- [Tool] download

**Optimization:**
- Clear brand mentions
- Product names in headings
- Direct links to resources

### Informational Intent
User seeks knowledge or understanding.

**Patterns:**
- How/what/why questions
- Definitions
- Explanations
- Guides and tutorials

**Optimization:**
- Answer-first structure
- Comprehensive explanations
- Examples and visuals
- Related concepts linked

### Transactional Intent
User wants to complete an action.

**Patterns:**
- Buy [product]
- [Service] near me
- Best price for [item]
- [Product] discount code

**Optimization:**
- Clear CTAs
- Pricing information
- Product specifications
- Comparison tables

### Commercial Investigation
User researches before transaction.

**Patterns:**
- Best [product] for [purpose]
- [Product] review
- [X] vs [Y]
- Top [category]

**Optimization:**
- Detailed comparisons
- Pros and cons
- Expert recommendations
- User testimonials

## Long-Tail Query Strategies

Long-tail queries (3+ words) are highly valuable for chatbot SEO:

**Characteristics:**
- More specific intent
- Lower competition
- Higher conversion potential
- Better match for natural language queries

**Examples:**

Short-tail (competitive): "running shoes"
Long-tail (targetable): "best running shoes for flat feet and overpronation"

Short-tail: "content marketing"
Long-tail: "how to create a content marketing strategy for B2B SaaS startups"

Short-tail: "project management"
Long-tail: "what project management methodology should small teams use for remote work"

**Optimization Approach:**
1. Identify specific problems your content solves
2. Create pages for each specific use case
3. Use natural, conversational language
4. Include modifiers (best, cheap, easy, fast, etc.)
5. Address specific demographics or situations

## Conversational Query Patterns

Chatbots process queries more conversationally than keyword-based search:

**Characteristics:**
- Full sentences
- Natural language
- Context-dependent
- Follow-up questions

**Examples:**

Traditional search: "python list comprehension syntax"
Chatbot query: "How do I use list comprehension in Python to filter a list?"

Traditional: "SEO best practices 2024"
Chatbot: "What are the most important SEO strategies I should focus on this year?"

**Optimization:**
- Write in conversational tone
- Answer complete questions
- Provide context for technical terms
- Structure for follow-up queries

- "Is [technology] worth learning?"

- "What causes [symptom]?"
- "How to treat [condition]?"
- "Is [symptom] serious?"
- "When should I see a doctor for [problem]?"

### Finance
- "How to [invest/save/budget]..."
- "What is [financial concept]?"
- "Best [financial product] for [situation]"
- "Should I [financial action]?"

- "Best [product] for [use case]"

- "Is [product] worth it?"

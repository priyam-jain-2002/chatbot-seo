# Evaluation and measurement

Baseline before changing production. Segment by brand/nonbrand, intent, geography, device and template where meaningful. Record dates, source, denominators and attribution limits. Search impressions, clicks, CTR, index coverage and query mix are leading indicators; qualified leads, accepted quotes, orders, conversion, contribution margin and repeat purchases are outcomes. A ranking or citation is not proof of revenue.

Build a fixed prompt suite including unbranded discovery, entity lookup, comparison, regional/serviceability, fact extraction and transactional questions. For each run record exact prompt, date, locale, surface/model, web-search mode, source URLs, answer and limitations. Repeat across independent sessions; report numerator/denominator for correct entity mention, citation, factual accuracy, completeness and actionability. Distinguish no result, wrong result and unavailable surface. Never infer proprietary ranking factors from a small sample.

Check initial HTML and rendered DOM, HTTP status/redirects, canonical, robots, sitemap URL membership, internal links and structured data. Verify new content is published at its real canonical page, enters sitemap and becomes accessible without unnecessary rebuilds when dynamic publishing is required. Search console inspection or platform diagnostics are separate from actual indexing. Test storefront checkout, lead form, quote requests and analytics event deduplication with permission; avoid real purchases or external messages without authorization.

Use controlled comparisons or clearly label observational before/after evidence. Account for seasonality, promotions, deployment changes and attribution gaps. Revisit priority gates after template changes; do not guarantee indexing, rankings or AI citations.
